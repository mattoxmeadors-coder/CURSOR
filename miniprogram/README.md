# 见家长 AI Copilot · 微信小程序版

这是一个可直接导入 **微信开发者工具** 的小程序工程。

## 导入方式

1. 下载整个仓库到本地
2. 打开微信开发者工具
3. 选择“导入项目”
4. **项目目录选择：`miniprogram`**
5. AppID 可先使用测试号或无 AppID 模式查看

## 当前已实现

- 首页三入口：
  - 开始准备这次见面
  - 和 TA 对齐口径
  - 生成当天作战方案
- 结构化输入：
  - 身份
  - 家庭待客风格
  - 父母背景
  - 见面性质
  - 在场成员
  - 主要压力点
  - 是否统一口径
  - 家庭是否强势
  - 补充描述
- 结果输出：
  - 风险等级
  - 用户画像
  - 核心风险点
  - 5 段式当天作战计划
  - 情侣协同建议
  - 礼物建议
  - 社媒/私域内容包
  - 模拟演练提示

## 目录结构

- `app.json`：全局配置
- `pages/index/*`：首页输入页
- `pages/result/*`：结果页
- `utils/copilot-data.js`：结构化内容数据
- `utils/copilot-engine.js`：结果生成引擎

## 说明

当前版本为 **纯前端本地规则引擎版**，不依赖云函数即可直接预览。  
后续你可以继续接入：

- 云函数
- 大模型接口
- 用户历史记录
- 情侣双人协同流程
- 模拟见家长角色扮演
